Verbind je AirKing Statiefventilator met Homey en bedien deze wanneer je weg van huis bent via Homey's ingebouwde Infrarood-zender. Je kan je ventilator ook in Flows gebruiken. Bijvoorbeeld: maak een Flow om je ventilator in te schakelen wanneer de buitentemperatuur hoger wordt dan 25°C, zodat je huis comfortabel blijft. Deze app werks ook op ventilatoren zonder WiFi. Voor ventilatoren met WiFi wordt de Tuya-app aanbevolen.
